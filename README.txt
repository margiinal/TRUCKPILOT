TRUCKPILOTE — PREMIÈRE VERSION CHAUFFEUR

Contenu :
- index.html : accueil de l'espace chauffeur
- feuille.html : modèle hebdomadaire existant, repris sans refonte de sa présentation
- profil.html : profil local du chauffeur
- manifest.json, icon.svg, service-worker.js : installation PWA et cache hors connexion

IMPORTANT : cette version est un prototype installable. Le profil et les données de la feuille restent sur l'appareil/navigateur. Il n'y a pas encore de comptes sécurisés, de synchronisation cloud, de partage multi-appareils ni d'envoi automatique par e-mail.

Pour tester : déployer le contenu du dossier sur un hébergement HTTPS (par exemple un nouveau site Netlify, sans remplacer le site actuel). Ouvrir index.html, puis utiliser « Ajouter à l'écran d'accueil » dans le navigateur Android.
